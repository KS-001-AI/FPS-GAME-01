# NEON BREACH · FPS GAME 01

A playable, standalone neon sci-fi first-person arena survival game.

## Play

Open [index.html](index.html) in Chrome, Edge, or Firefox on desktop. Click **ENTER THE ARENA**, then click inside the game to capture the mouse.

No dependencies, installs, assets, build tools, or servers required.

## Controls

| Control | Action |
| --- | --- |
| W / A / S / D | Move |
| Mouse | Look and aim |
| Hold left mouse button | Fire automatic pulse carbine |
| Shift | Sprint |
| R | Reload |
| Esc | Release mouse and pause |
| Click canvas | Resume |

## Features

- Custom HTML5 Canvas raycasting first-person renderer
- Neon arena with perspective walls and minimap
- Combat drones and elite variants
- Wave progression and escalating difficulty
- Automatic weapon, recoil, ammo reserves and reloads
- Hit detection, critical strikes, points, health and healing between waves
- Simple synthesized sound effects and responsive HUD

## Roadmap

Multiple weapons, more intelligent enemies, upgraded maps, power-ups, controller/mobile support, music, persistent leaderboard, and multiplayer.

## Deploy with GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**, then save. The game can then be played at the GitHub Pages URL. The site may take a short time to publish.

MIT-style learning-friendly prototype: source currently lives in one self-contained `index.html` file.
